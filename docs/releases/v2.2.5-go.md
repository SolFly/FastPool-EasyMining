FastPool EasyMining now provides portable executable releases for Windows, macOS, and Linux on Intel/AMD and ARM64 systems.

### Choose your system

| System | Download target | Native test runner |
| --- | --- | --- |
| Windows, Intel/AMD 64-bit | `windows-amd64` | Windows Server 2025 |
| Windows on ARM | `windows-arm64` | Windows 11 ARM64 |
| macOS, Intel | `darwin-amd64` | macOS 15 Intel |
| macOS, Apple Silicon | `darwin-arm64` | macOS 15 Apple Silicon |
| Linux, Intel/AMD 64-bit | `linux-amd64` | Ubuntu 24.04 x64 |
| Linux, ARM64 / 64-bit Raspberry Pi OS | `linux-arm64` | Ubuntu 24.04 ARM64 |

Each target has a raw executable and a `fastpool-easymining-v2.2.5-go-<target>.zip` portable package. ZIPs contain the executable, a start guide, example configuration and the MIT license. The browser UI is embedded; SQLite is compiled into the executable. Linux binaries are statically linked. Windows builds do not require the compiler or MSYS2 on the destination computer. macOS uses system libraries.

### Verification

The release waits for Go race tests/vet, JavaScript regressions, native unit tests, executable OS/CPU checks, startup health checks and a SQLite/key-persistence restart on every target. Windows startup checks remove compiler directories from the child process PATH. `BUILD_INFO.json` records all six targets and the exact source commit. `SHA256SUMS` covers every executable and package.

Windows and macOS executables are unsigned; macOS packages are not notarized. These are console servers with a browser UI, not desktop installers. Refer to the tested runner versions above; older OS versions and 32-bit systems are not validated by these releases.

### Preserved downloads and behavior

The full Linux amd64 distribution remains available as `fastpool-easymining-v2.2.5-go.zip`, along with the full GitHub source package. Version 2.2.4-go remains available unchanged.

Buying, accounting, spending controls and account credentials retain the behavior of 2.2.4-go. Keep your existing data directory and matching `master.key` when upgrading. A server restart pauses and disarms buying; sync, review, arm and start explicitly.
